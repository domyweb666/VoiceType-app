# 詞彙表

**狀態**：全部「暫定，未經使用者驗證」。名字由米定；我只把現有說法撈出來、標出同物多名。樹狀測試與方向測試裡，使用者自己怎麼叫這些東西，回填到「來源」欄。

| 東西或動作 | 定下來的名字 | 拿掉的說法 | 出現在哪 | 來源 |
|---|---|---|---|---|
| 這個 app | **米說** | VoiceType（Info.plist 顯示名、首頁左上角） | 圖示名、權限框、設定「關於」 | 米選（延續網頁版） |
| 潤飾後的那份 | **文字稿** | 潤飾稿、成品、整理後 | 清單、詳情、完成面板 | 暫定 |
| 語音直接轉出來的那份 | **口語稿** | 逐字稿、原文、raw | 詳情分段控制 | 暫定 |
| 還沒轉成文字的錄音 | **待轉錄** | 未完成錄音、待處理、pending | 首頁方塊、首頁區段 | 暫定 |
| 錄完自動轉文字並潤飾 | **整理**（動詞）／**整理中** | 轉錄＋潤飾兩步、步驟 1/2、步驟 2/2 | 錄音面板進度 | 暫定。⚠️ 使用者不需要知道是兩步，但失敗時要說是哪一步沒成功 |
| 再潤飾一次 | **重新潤飾** | 只潤飾文字稿（調提示詞後重跑） | 詳情工具列 | 暫定 |
| 完成一篇得到的獎勵 | **收成**（名詞）／**一根玉米**（單位） | 成就、點數 | 完成面板、穀倉 | 網頁版 |
| 收成的地方 | **穀倉** | 收藏、成就頁 | 首頁導覽鈕、推入頁 | 網頁版 |
| OpenAI 給的那串字 | **金鑰** | API Key、API 金鑰、轉錄金鑰 | 設定、首頁橫幅 | 暫定。⚠️ 設定頁欄位標題可以寫「OpenAI 金鑰（API Key）」一次，其他地方只叫金鑰 |
| 把文字稿帶走 | **匯出文字稿** | 匯出全部文字稿、匯出備份、匯出 ZIP | 「⋯」選單、設定 | ⚠️ 現在有兩個入口兩個名字（流程樹狀測試猜會掉），要米決定是不是同一件事 |
| 換手機搬資料 | **備份** | 匯出備份、匯入備份 | 設定 → 資料 | 暫定 |

## 按鈕的字

動詞帶對象，按之前就猜得到結果。不准用「確定」「提交」「OK」。

| 情境 | 寫法 |
|---|---|
| 刪除確認 | 「刪除這篇文字稿」／「取消」 |
| 重新潤飾確認 | 「重新潤飾，蓋掉這篇」／「另存一篇」／「取消」 |
| 權限被拒 | 「打開『設定』」／「先不要」 |
| 首次金鑰橫幅 | 整列可點，箭頭指向設定，不用按鈕字 |

## 語氣規則

- 畫面上的字只能用這張表裡的名字。
- **可愛的話只能由角色（玉米）說**：空狀態插圖旁、收成那一刻。
- **錢、錯誤、權限用平實語氣，第一句回答有沒有損失**：「錄音還在待轉錄，沒有被扣款，連上網路後會自動轉。」不寫「哎呀出錯了」。
- 使用者自己按取消，不跳任何訊息。
