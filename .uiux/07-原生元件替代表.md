# 原生 iOS 元件替代表（2026-11-08）

> 米問：有沒有原生 iOS UI 可以換掉現在自己畫的風格。下面是米說現在每個自畫的東西，對應到系統現成的元件。
> 「原生」指 SwiftUI 內建、iOS 26 會自動套液態玻璃的那些。用原生的好處是系統改版會跟著變、深色與大字不用自己顧、上次那種大標貼左緣的怪問題會少很多。

## 一、結構（這一塊最該換）

| 現在 | 原生替代 | 換了之後 |
|---|---|---|
| 三頁左右滑＋最上面一排小點 | **底部分頁列**（`TabView` 標準樣式）：文字稿／錄音／設定三個分頁，iOS 26 是浮在底部的玻璃列 | 小點那排不見了；系統大標回來、位置正確；錄音鈕可以精準置中；搜尋框照系統放。米 11/02 選左右滑，這等於推翻那次決定 |
| 自己畫的大標（`PageHeading`）＋空的系統標題列 | 系統大標（`navigationTitle`，大標模式） | 捲動時大標自動縮成上方小標，跟設定 App 一樣 |
| 推進去時手動藏小點（`PageDotsVisibility`） | 不需要 | 刪掉一個檔 |

這兩個問題（錄音鈕偏下、文字稿上面空一塊）都是左右滑結構帶出來的。換成底部分頁列，兩個一起消失。

## 二、元件

| 現在 | 原生替代 | 備註 |
|---|---|---|
| 主要按鈕（玉米黃膠囊，`PrimaryButtonStyle`） | `.buttonStyle(.borderedProminent)`＋`.controlSize(.large)`；iOS 26 有 `.glassProminent` | 顏色吃 App 的強調色 |
| 金色文字鈕（`TextButtonStyle`） | `.buttonStyle(.borderless)` 或預設按鈕 | 顏色同上 |
| 空清單的玉米插圖（`CornIllustration`） | `ContentUnavailableView`（系統的空狀態：圖示＋標題＋說明＋按鈕） | 玉米可以當它的圖片留著，或換 SF Symbol |
| 面板頂上的圖示圓（`IconCircle`） | SF Symbol 加 `.symbolRenderingMode(.hierarchical)`、`.symbolEffect` 動畫 | 打勾、轉圈可以用系統動畫 |
| 狀態條（`StatusStrip`：已複製、已刪除・復原、失敗） | 沒有完全對應的。失敗可以改 `.alert`；「已複製」用觸覺回饋＋按鈕圖示變勾；「已刪除・復原」系統沒有，保留自己的 | 這個建議留著，只改長相跟著系統 |
| 白卡片＋爆米花底 | `List`／`Form` 的 `.insetGrouped`（現在其實已經是），底色用系統的 `systemGroupedBackground` | 要不要保留爆米花色是品牌選擇，見第三節 |
| 錄音面板 | 已經是系統 sheet（半頁、可拉高），不用換 | |
| 詳情頁編輯器 | 已經是 `TextEditor`＋系統工具列，不用換 | iOS 26 工具列自動變玻璃 |
| 搜尋 | 已經是系統 `.searchable`，不用換 | |
| 統計卡 | 留著（`Grid` 放在清單列裡，本來就是系統元件組的） | |

## 三、顏色

| 做法 | 長什麼樣 |
|---|---|
| 全系統色 | 白／淺灰底、黑字、只有一個強調色（建議玉米金）。最像內建 App，最不像米說 |
| 保留品牌底色（建議） | 結構與元件全換原生，底色留爆米花、強調色留金色。看起來是原生 App，但認得出是米說 |

現在 15 個顏色資源，換成「系統語意色＋1 個強調色（＋爆米花底）」大約剩 2～3 個。

## 四、一定留自己畫的

- **首頁錄音鈕**（金環＋酒紅圓盤＋玉米）：這是米說的臉，系統沒有對應的。
- **錄音波形**、停止鈕的呼吸動畫。

## 五、建議

結構換原生（底部分頁列＋系統大標），元件能換的換，顏色保留爆米花底和金色強調色。錄音鈕、波形、「已刪除・復原」留自己畫。
