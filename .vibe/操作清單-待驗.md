### 一段錄音驗完（一小時多，大部分時間手機放著）

不用自己講一小時。電腦放一段中文音檔（你的課程或 Podcast 都可以），手機放旁邊開錄。下面這些都在同一段錄音裡做，時間不用很準，每做完一項看一眼手機，記下你看到什麼：

- [ ] 第 5 分鐘：請人打給你，不要接。錄音有沒有斷，計時有沒有繼續走。
- [ ] 第 10 分鐘：請人再打一次，接起來講 30 秒掛掉，不要碰米說。解鎖回到米說，計時有沒有自己接著走。
- [ ] 第 15 分鐘：設一個 1 分鐘後響的鬧鐘，響了按掉。
- [ ] 第 20 分鐘：接上耳機或 AirPods，過一分鐘拔掉。
- [ ] 第 25 分鐘：開 YouTube 放 30 秒再關掉，回到米說。
- [ ] 然後鎖屏放著到一小時，解鎖按停止。面板最上面寫「中間斷過幾次，共多久」，抄給我。
- [ ] 待轉錄或文字稿裡這段的長度，跟計時差多少。
- [ ] 設定 → 關於米說 → 匯出診斷紀錄，把檔案傳給我。這一份最有用，哪裡斷了、接回花幾秒我都看得到。裡面只有時間和數字。

這段停止後會自動送去轉錄，大約花 0.3 美元。文字稿可能出不來或只有口語稿，那是第二批要修的，這批不算錯。第二批出來之前，真正要用的長錄音還是可能少字。

## 甲、金鑰（組塊 B）

- [ ] 打開 TestFlight，告訴我有沒有 0.1.4 (5)。裝好打開，首頁跟上一版比有什麼不一樣。

- [ ] 欄空著直接按「儲存並驗證」，看到哪一行字。
- [ ] 貼一串亂打的（例如 `sk-亂打123`）再按。按下去那一瞬間按鈕變什麼字，幾秒後那一行寫什麼。

## 乙、錄音不會丟（組塊 C）

- [ ] 第一次按中間的鈕。系統問麥克風時先按「不允許」。面板寫什麼、有哪兩顆鈕。按「打開『設定』」會不會直接跳到米說那一頁。把麥克風打開回來。
- [ ] 按鈕開始錄，講 30 秒。告訴我：計時有沒有在跳、波形有沒有跟著你的聲音動、停止鈕外圈有沒有在呼吸、按下去手機有沒有震一下。
- [ ] 錄 2 分鐘，中間把螢幕鎖起來 1 分鐘再解鎖。停止後有沒有變成文字稿（或在待轉錄裡），長度是不是 2 分鐘左右。
- [ ] 錄到一半請人打電話給你，接起來講幾句再掛掉。回到米說，面板寫什麼。按「繼續錄」再講幾句，停止。
- [ ] 錄 1 分鐘，不按停止，直接從多工畫面把米說滑掉。重開米說，首頁有沒有「待轉錄 1 個」，點進去那段長度差多少。
- [ ] 開飛航模式錄一段，停止。面板寫什麼。
- [ ] 進待轉錄，左滑刪掉一個，跳出來的確認寫什麼，刪掉後首頁數字有沒有少。
- [ ] 連續錄 35 分鐘（手機可以鎖著放口袋），停止。米說有沒有閃退、這段有沒有收好。

## 丙、說話變草稿（組塊 D，最重要的一段）

這段的第一條就是米說存在的理由：講完、拿到草稿、貼進 Word。

- [ ] 講 2 分鐘停止。告訴我：面板依序出現哪些字、等了幾秒、最後寫什麼。第一次會多一行說錄音送到 OpenAI、費用算你的金鑰，有沒有看到。
- [ ] 不用按複製，直接打開 Word（或備忘錄）貼上。貼出來的是不是剛剛那段。
- [ ] 讀完那段告訴我：像不像你講的；有沒有它自己加的句子或標題；錯字有沒有改。
- [ ] 講 5 分鐘、中間換三個話題。草稿有沒有分段。
- [ ] 同一件事刻意講三次。草稿是不是只留講得最完整的那一次，有沒有把三次拼成一句新的。
- [ ] 講到一半時關掉網路（整理中那幾秒關），面板寫什麼、有沒有「重試」。開網路按重試，拿不拿得到草稿。
- [ ] 錄 25 分鐘，整理到「第 2／3 段」時關網路。面板寫什麼。開網路按重試，看它是不是從第 2 段接著轉（第 1 段不會再出現「第 1／3 段」）。
- [ ] 開飛航模式錄一段，關掉米說。關飛航、打開米說回首頁，等一下，那段有沒有自己出現在「文字稿」裡。
- [ ] 錄完在面板按「先放著」，面板收起來。過一下進「文字稿」，那段有沒有整理好。剪貼簿有沒有被它換掉（照設計，收起來之後就不會動剪貼簿）。

## 丁、找回來、改一改、刪了救得回（組塊 E）

- [ ] 首頁左上「文字稿」。最新的是不是在最上面，每一列看得到什麼。
- [ ] 搜尋一個你講過的字，只剩含這個字的嗎。搜一個沒講過的字，畫面寫什麼，按「清除搜尋」回來。
- [ ] 點進一篇。上面能不能切「文字稿｜口語稿」；有沒有寫用哪個模型潤飾的。
- [ ] 在文字稿裡改幾個字，停下來 2 秒，從多工畫面滑掉米說，重開進同一篇。改的字還在嗎。
- [ ] 按下面的「複製」，貼到別處對不對；按「分享」選「儲存到檔案」，到「檔案」App 找得到那個 .txt 嗎。
- [ ] 按「重新潤飾」，跳出來的選項寫什麼。選「另存一篇」，清單是不是多一篇、原本那篇沒變。
- [ ] 再按一次「重新潤飾」，潤飾中按「取消」。原本的字有沒有被改到。
- [ ] 右上「⋯」刪掉這篇，回到清單底下有沒有「已刪除」和「復原」。5 秒內按復原，那篇是不是回到原位。

## 戊、自己調草稿的樣子（組塊 F）

- [ ] 設定 → 使用習慣，把「整理好自動複製」關掉，再錄一段。完成時面板寫什麼，剪貼簿是不是沒變。驗完再打開。
- [ ] 設定 → 潤飾 → 自訂詞彙，加「DOMYWEB」（或你常講、常被寫錯的詞）。錄一段講到它，草稿寫對了嗎。
- [ ] 設定 → 潤飾提示詞，在最後加一句好認的規矩（例如「每段開頭加一個 ★」），錄一段，草稿有沒有照做。再按「還原預設」，確認框寫什麼，還原後再錄一段是不是回到原本的樣子。
- [ ] 設定 → 模型換成另一個，錄一段，詳情頁寫的模型是不是新的那個。換回來。
- [ ] iPhone 字級拉到最大，走一遍首頁、錄音面板、文字稿詳情、設定。有沒有字被切掉、按鈕疊在一起。

- [ ] 設定最下面「關於米說」寫的版本是不是 0.1.4（5）。
