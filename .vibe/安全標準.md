**判定時間**：2026-10-31，米親自勾選確認
**判定依據**（用架構藍圖判斷，不用舊 Flutter 的資料夾結構，避免把凍結的桌面版、網頁版算進來）：
- Mobile App（95%）：`ios/` 有 `Info.plist` 與 Xcode 專案；架構藍圖是只跑 iPhone 的 SwiftUI App。
- 有調用 LLM（90%）：潤飾把口語稿送 OpenAI 的 chat completions，轉錄送 OpenAI 語音 API；提示詞使用者可改。
- 沒勾：Web 應用（30%，網頁版不在這次範圍）、CLI／桌面（20%，舊桌面版已凍結）、純 API（0%，沒有自己的伺服器）。

## 適用的權威標準

- ✅ OWASP MASVS（手機 App）
- ✅ OWASP Top 10 for LLM Applications（因為有調用 OpenAI）

## 這個 App 的風險長什麼樣（白話）

米說沒有帳號、沒有自己的伺服器，資料只在手機裡，對外只連 OpenAI。所以最大的三個風險是：
1. **金鑰外洩**：別人拿到米的 OpenAI 金鑰，就能花他的錢。
2. **文字稿外洩**：文字稿是米散步時講的想法，拿到手機或備份檔的人不該讀得到。
3. **帳單失控**：程式寫錯，一直重試或重複上傳，米的 OpenAI 帳單會暴增。

## 必查清單

### 一、金鑰（MASVS-STORAGE、MASVS-CRYPTO、MASVS-AUTH、LLM06）

- [ ] 🔴 OpenAI 金鑰只存在 iOS Keychain，不存在 UserDefaults、檔案、SwiftData／SQLite、備份檔裡。
  被打中會怎樣：手機備份或匯出檔被別人拿到，他就能用你的金鑰花你的錢。
- [ ] 🔴 金鑰不出現在任何 log（`print`、`os_log`、`NSLog`）、錯誤訊息、「複製錯誤詳情」、當機報告裡。
  被打中會怎樣：你把錯誤訊息貼給別人求救時，金鑰就跟著出去了。
- [ ] 🔴 金鑰不寫死在程式碼、不進 git、不放在 CI 的 log 裡。
  被打中會怎樣：repo 是 public，寫進去等於公開給全世界。
- [ ] 🔴 刪除金鑰時，Keychain 裡那筆真的被刪掉（不是只清畫面）。
  被打中會怎樣：你以為刪了，其實還在手機裡。
- [ ] 🟡 金鑰欄預設遮住（顯示成點點），要按眼睛圖示才顯示。

### 二、文字稿與錄音的本機儲存（MASVS-STORAGE、MASVS-CRYPTO）

- [ ] 🔴 歷史（口語稿、文字稿）存檔要加密：用 iOS 的檔案保護（Data Protection），再加上用 CryptoKit 加密、金鑰存 Keychain。不准明文存在 UserDefaults 或沒加密的資料庫。
  被打中會怎樣：有人拿到你沒上鎖的手機或電腦上的備份，可以直接讀你所有的文字稿。
- [ ] 🔴 錄音檔（待轉錄、救回檔）存在 App 自己的資料夾，開檔案保護；轉錄並存好口語稿之後才刪（照 PRD）。
- [ ] 🔴 加密用平台原生 API（CryptoKit），不用 MD5、SHA-1、DES、RC4，不自己發明加密；隨機數用系統的安全亂數。
- [ ] 🔴 文字稿內容不寫進 log。
  被打中會怎樣：log 會被當機報告、除錯工具帶走，等於把你的想法外流。
- [ ] 🔴 匯出備份檔不含金鑰（PRD 已定）。
- [ ] 🟡 退到背景時，多工畫面的縮圖可以考慮遮住文字稿內容。米說不是金融 App，列建議項。
- N/A 截圖防護：米說沒有付款或證件畫面。

### 三、網路連線（MASVS-NETWORK）

- [ ] 🔴 只連 `https://api.openai.com`，全部 HTTPS；保持 iOS 的 ATS 開著，不加任何「允許明文連線」的例外。
- [ ] 🔴 不忽略憑證錯誤（不寫「信任所有憑證」那種程式）。
  被打中會怎樣：在咖啡廳的假 Wi-Fi 上，別人可以偷看你送出去的錄音和金鑰。
- [ ] 🔴 音訊與文字只送到 OpenAI，不送到任何其他地方（沒有第三方分析、沒有自己的伺服器）。
- [ ] 🟡 憑證綁定（certificate pinning）：米說不處理金錢或醫療資料，列建議項；做的話 OpenAI 換憑證時 App 會連不上，要評估。

### 四、花費與用量（LLM04）

- [ ] 🔴 每個請求有重試上限：轉錄最多 4 次、潤飾最多 3 次（照 PRD），不准無限重試。
- [ ] 🔴 自動續轉遇到失敗就停，不准自己一直重跑（照 PRD）。
  被打中會怎樣：網路怪怪的那一晚，App 在背景把同一段錄音上傳幾百次，帳單暴增。
- [ ] 🔴 同一段錄音不會被重複送出（例如按兩次重試、或續轉和手動重試同時跑）。
- [ ] 🔴 單次上傳有大小上限（超過 10 分鐘切段、單檔不超過 OpenAI 上限），超過的不送。
- [ ] 🟡 設定頁顯示費用粗估，並提醒米可以在 OpenAI 後台設每月用量上限（App 自己沒有伺服器，擋不了總額，只能靠 OpenAI 後台）。

### 五、提示詞與 AI 輸出（LLM01、LLM02、LLM06、LLM09）

- [ ] 🔴 系統提示詞和口語稿分開送（system 與 user 兩個角色），不把口語稿拼進系統提示詞裡。
  被打中會怎樣：口語稿裡剛好有一句像指令的話，AI 可能照著做，草稿就變成別的東西。
- [ ] 🔴 AI 回來的草稿當純文字顯示，不當網頁或 Markdown 渲染、不載入裡面的連結或圖片、不執行任何內容。
- [ ] 🔴 系統提示詞裡不放任何金鑰或秘密（提示詞使用者可以看、可以改）。
- [ ] 🔴 只送這次要處理的那一段，不把其他篇文字稿塞進請求。
- [ ] 🟡 詳情頁保留口語稿可對照，讓米看得出 AI 有沒有聽錯或改錯（LLM09 過度依賴）。
- N/A 系統提示詞外洩防護：提示詞本來就是使用者可以看、可以改的，不是秘密。
- N/A 多使用者 context 隔離：米說只有一個使用者、資料只在一支手機。

### 六、權限與隱私（MASVS-PRIVACY）

- [ ] 🔴 只要麥克風權限；不要位置、聯絡人、相簿、相機、追蹤（ATT）。通知權限在第一次完成之後才問（照 `.uiux/06-首次體驗.md`）。
- [ ] 🔴 `Info.plist` 的麥克風說明照實寫用途；App 的隱私資訊清單（Privacy Manifest）與 App Store 隱私問卷照實填「收集音訊、送第三方（OpenAI）轉錄」。
  被打中會怎樣：送審被退，或使用者覺得被騙。
- [ ] 🔴 米可以刪除單篇文字稿，也可以刪除全部資料（含待轉錄的錄音檔）。
- [ ] 🔴 不放任何第三方分析或廣告 SDK。
- [ ] 🟡 第一次上傳前用一句話講清楚：錄音會送到 OpenAI、費用算在你的金鑰上（照 `.uiux/06-首次體驗.md`）。

### 七、平台互動（MASVS-PLATFORM）

- [ ] 🔴 捷徑、動作按鈕、Siri、分享表單這些從外面進來的入口，只做「開始錄音」「匯入音檔」這類動作，不接受外部傳進來的指令去刪資料或改設定。
- [ ] 🔴 從分享表單或「檔案」匯入的音檔與備份檔，先檢查格式與大小再處理；匯入備份不准蓋掉現有資料，除非畫面講清楚且米同意（照 PRD）。
- N/A WebView：米說不用 WebView。以後要加，回來補這一條。
- N/A 深層連結網址：流程裡明確不做（`.uiux/02-流程.md`）。

### 八、程式與建置（MASVS-CODE、LLM05）

- [ ] 🔴 第三方套件越少越好；有用到的話，從官方來源用 Swift Package Manager 安裝、鎖定版本。
- [ ] 🔴 GitHub Actions 的簽章素材全部放 GitHub Secrets，不 echo 到 log、不存成 artifact；上傳的 artifact 只能是 App 本身。
- [ ] 🔴 部署目標 iOS 16 以上，用 Xcode 預設的編譯安全選項，不關掉。
- [ ] 🟡 直接用 URLSession 呼叫 OpenAI，不另外裝 OpenAI SDK（少一個供應鏈來源）。

### 不適用的整組

- N/A MASVS-AUTH 的登入、token、生物辨識：米說沒有帳號、不登入。
- N/A MASVS-RESILIENCE（防越獄、混淆、防除錯）：個人工具、不處理金錢。
- N/A LLM03 訓練資料污染、LLM10 模型竊取：只呼叫 OpenAI API，不自己訓練模型。
- N/A LLM07 不安全的工具、LLM08 過度授權的 agent：AI 沒有任何工具或自動動作，只回傳文字。明確不做清單裡的「自動發文到社群」如果以後要做，這兩條要回來補。
