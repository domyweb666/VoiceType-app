## 這片是什麼（一句話）

一台最陽春的錄音機：按首頁的玉米鈕升起面板，看得到計時在跳、波形在動；按 80pt 停止鈕，錄音變成一個 16 kHz 單聲道的 WAV 檔，收進 App 自己的「待轉錄」資料夾。還看不到待轉錄列（C6）、還不處理權限被拒（C2）、鎖屏背景（C3）、救回（C4）。

- [ ] 我對著手機講話，應該看到波形跟著聲音動；安靜時波形幾乎平。
- [ ] 我試著把面板往下滑，應該滑不掉（面板不可下滑關閉）。
- [ ] 我按停止鈕，應該看到面板收起、回到首頁、沒有閃退。手機有「開始」與「停止」兩種不同的震動（觸覺回饋開著時）。
- [ ] 我開「減少動態」再錄，應該看到波形變成一條固定位置的音量條、停止鈕不呼吸但旁邊有紅點。

- [ ] （機器）錄完的檔是 WAV、16 kHz、單聲道、16-bit；檔頭的長度欄位跟實際資料一致；存在 App 自己的資料夾、檔案保護開著。

## ⛔ 絕對不准做

- 不准動到：組塊 A、B 已驗的畫面與程式（`HomeView` 只准接上「按鈕升起面板」這一條線）、`Tokens.swift`、workflow。
- 不准把聲音存進記憶體整捲抱著（舊版的死法）；邊錄邊寫檔。
- 不准出聲（提示音）；不准波形每跳都震。
- 不准在這片做：權限被拒畫面（C2）、背景模式與中斷（C3）、救回（C4）、待轉錄列（C6）、停止後的轉錄流程（D）。

## 🎯 每條的意圖

- 「計時與波形」只回答一件事：它還在聽嗎（02-流程第②格）。
- 「不可下滑」是 2-5 的死法：錄到一半誤滑就丟掉。
- 「邊錄邊寫檔、16 kHz 單聲道 WAV」是 C4 救回與 C5 35 分鐘不爆的地基，也是 OpenAI 收得了的格式。
- 「開始／停止觸覺不同」是因為使用者常不看螢幕就開始說。
- 「檔案保護」是安全標準二：拿到沒上鎖的手機也讀不到錄音。鎖屏後還要能繼續寫（C3），所以用「第一次解鎖後可用」那一級，不是「鎖上就關」那一級。

- [ ] 我在詢問框按「不允許」，應該看到面板換成兩行字「米說聽不到你的聲音」「麥克風權限是關的。到『設定』打開米說的麥克風，回來就能錄。」，下面一整條「打開『設定』」和一顆「先不要」。
- [ ] 我按「打開『設定』」，應該直接跳到 iOS 設定裡米說那一頁（有麥克風開關）；打開後回米說再按玉米鈕，應該能錄（不再問）。
- [ ] 我按「先不要」，應該回首頁，沒有別的訊息。
- [ ] 權限已經被拒的狀態下再按玉米鈕，應該直接看到那個被拒面板，不會再跳系統框（系統只問一次）。

## ⛔ 絕對不准做
- 不准自訂權限說明畫面（直接用系統框）；不准要麥克風以外的權限。

## 🎯 意圖
- 「第一次按才問」：權限在使用者自己做動作的那一刻問，答應率最高（2-12）。

# 標準清單（片 D1 本機存檔、D2 單段轉錄、D3 切段續轉、D4 潤飾）

> 查證（2026-11-01 官方文件）：轉錄 `POST /v1/audio/transcriptions` multipart（file、model、prompt、response_format=json → `{text}`），檔案 25 MB 上限，格式含 wav；模型 `gpt-4o-mini-transcribe`（舊版、網頁版）已 Deprecated、2027-02-26 關閉，官方推薦 `gpt-transcribe`（每分鐘 0.0045 美元）→ **本版用 gpt-transcribe**。潤飾 `POST /v1/chat/completions`，system／user 分開，`choices[0].message.content`；`gpt-5.4-mini` 存在（輸入 0.75／輸出 4.50 美元每百萬 token，網頁版預設）、`gpt-4o-mini` 存在但 Deprecated（0.15／0.60）→ 預設 gpt-5.4-mini、第二選項 gpt-4o-mini（F4）。

## D1 本機存檔（M5）
- [ ] （機器）存一篇讀回來一樣；最新在最上面；改一篇再讀是改過的；刪一篇讀不到。
- [ ] （機器）磁碟上的檔不含明文（搜口語稿內容與欄位名都找不到）。
- [ ] （機器）放一個壞檔進去：其他篇照讀、壞檔被搬到 Unreadable/、沒被刪，畫面拿得到「1 篇讀不到」。
- [ ] （機器）換一個實例讀得到同一把 Keychain 金鑰的檔。
- ⛔ 不准用 UserDefaults 或沒加密的資料庫；加密只准 CryptoKit（AES-GCM）；金鑰只在 Keychain（ThisDeviceOnly）；寫檔原子；壞檔絕不刪。

## D2 單段轉錄（M3）
- [ ] （機器）送出的是 multipart，帶模型、檔案（audio/wav）、提示詞；回來的 `text` 就是口語稿。
- [ ] （機器）暫時錯誤（5xx）重試後成功；金鑰錯（401）只送一次；一直壞最多送 4 次就放棄。
- [ ] （機器）提示詞 200 字內：繁體提示＋專有名詞＋前一段結尾。
- ⛔ 轉錄模型名要查證（已查）；只送這一段；重試只對 M11 說可重試的錯。

## D3 切段與續轉（M3）
- [ ] （機器）25 分鐘切成 10／10／5 三段、每段完整 WAV；10 分鐘以內不切。
- [ ] （機器）第二段失敗後再來，只送第二、三段；最後整篇接起來；第二段提示詞帶第一段結尾。
- [ ] 米：25 分鐘錄音轉一半斷網 → 恢復後重試只接著轉失敗段（等 D5 接上才驗得到）。
- ⛔ 單段不超過 25 MB（10 分鐘 = 19.2 MB）；成功段絕不重傳；進度檔跟錄音檔放一起、錄音刪了才一起清。

## D4 潤飾（M4）

- ⛔ 不把口語稿拼進 system；不送別篇；回來的當純文字（畫面層）；最多 3 次。
