- [ ] （機器）一小時的錄音切成 11～13 段，每段 4:30～5:30，刀在那一分鐘裡最安靜的地方；不滿 30 秒的尾巴併進前一段；5 分 30 以內不切。
- [ ] （機器）不再另存切段檔：每段直接從原檔讀那一段送出。
- [ ] （機器）舊版照 10 分鐘切的進度檔對不上 → 從頭轉，不拿舊段的字接新段。

## S2-2 等久一點、檢查回來的字
- [ ] （機器）轉錄、潤飾每次請求等 180 秒。
- [ ] （機器）潤飾回來不是正常結束（`finish_reason` 不是 stop）→ 當失敗，不存半篇。
- [ ] （機器）轉錄回空字、或字數少於這段講話秒數該有的量 → 重送一次；還是少 → 文字稿標「第 N 段可能漏字」。

## S2-3 潤飾分塊
- [ ] （機器）口語稿照句尾切，每塊約 2,000 字；一塊一塊送，每塊好了就存進這篇；第 3 塊失敗再來只送第 3 塊以後。
- [ ] 一小時的稿整理完 → 文字稿從頭到尾都在，沒有哪一段整段消失。

## S2-4 沒做完自己接著做
- [ ] 整理到一半開飛航一分鐘再關，回到米說 → 接著做，不從頭來（方案驗收第二批第 2 項）。
- [ ] 潤飾做到一半鎖屏十分鐘，回來 → 那篇自己接著潤飾完（第 3 項）。
- [ ] （機器）進度檔不是明文（安全標準二）。

## S2-5 錄音留存
- [ ] 打開一篇剛錄的 →「⋯ → 從錄音重新轉錄」→ 拿到新的口語稿與文字稿（第 4 項）。
- [ ] （機器）錄音在文字稿存好之前絕不刪；存好後再留 7 天，或空間剩不到 1 GB 才刪；潤飾一直失敗的不刪；刪那篇文字稿時錄音一起刪。

## S2-6 金鑰與錯誤分類
- [ ] 錄音中鎖屏、同時在補轉舊錄音 → 待轉錄不會出現叫我刪掉的紅字。
- [ ] （機器）紅字只給 OpenAI 真的拒收的（4xx 非 401／429）；其他錯等一下再試。

## S2-7 停止後撐久一點
- [ ] 整理中螢幕不會自己暗掉。
- [ ] 整理中按鎖屏，30 秒內解鎖 → 手上那段已經做完。

## S2-8 單筆整理、改字
- [ ] 待轉錄有一筆失敗的 → 左滑或點開有「整理這一個」，按了只整理那一筆。
- [ ] 完成面板那顆按鈕的字講的是真的會發生的事。

## S2-9 刪除全部資料
- [ ] 設定 →「刪除全部資料」→ 確認框講清楚會刪什麼、救不回來 → 按刪除 → 文字稿、待轉錄、留存錄音都沒了；金鑰還在。
- [ ] 按取消 → 什麼都沒少。

## ⛔ 絕對不准做
- 不准在文字稿存好之前刪任何錄音（米：「都 ok 了，才刪」）。
- 不准動錄音本身（第一批 Recorder、MicrophoneCapture、CaptureWatch）。
- 不准把口語稿、文字稿、金鑰寫進診斷紀錄。
- 刪除全部資料不准刪金鑰（另有鈕），不准沒過確認框就刪。
- 不准加這批沒列的重試；重試照方案的次數。

## 🎯 每條的意圖
- 5 分鐘切在靜音：一段太長會被截斷或超時，切在句子中間會讓兩段都斷一個字。
- 分塊潤飾：一小時的稿一次送會超時，結局是只拿到口語稿。
- 留錄音：漏字時還有原音可以救，這是米最怕的事。
- 刪除全部資料：上架審查要，也是米對自己的資料有最後決定權。
