## 這片是什麼（一句話）

`ios-native/` 裡一個空的 SwiftUI App「米說」，加一條**不需要簽章**的 GitHub Actions 工作流程。推上 GitHub 就會在雲端的 Mac 上產生專案、編模擬器版、跑一個空的單元測試、跑格式與規矩檢查。證明沒有 Mac 也編得過。

## 🎯 每條的意圖

- 「推上去就自動跑、不用 secret」是為了證明米沒有 Mac 也能繼續，而且在 secret 設好之前所有機器驗證都走這條路。
- 「步驟名字看得懂」是為了讓米不懂程式也能在紅燈時指出是哪一步壞了。
- 「至少 1 個測試通過」是為了確認測試這條水管真的通，後面每片的機器驗證都靠它。
- 「沒有 .xcodeproj 進 repo」是為了專案檔由設定檔描述、在雲端產生，米在 Windows 上也改得了設定、不會被 Xcode 專案檔的合併衝突卡死。
- 「名稱、Bundle ID、部署目標」是為了跟 `ios/` 與 `README-release.md` 的上架設定一致，A3 接簽章時不用改。
- 「故意加 print 要變紅」是為了證明規矩不是寫在紙上，是機器在擋；這條驗的是 voice-lock 那台機器真的接上 CI。
- 「手動也能跑」是為了之後米想重跑不用做假 commit。
- 「紀錄裡沒有 secret 與簽章」是為了安全標準八：這條工作流程是 public repo 上任何人都看得到的。
