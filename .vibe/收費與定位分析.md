## 一句話

我建議：**訂閱為主（Apple 原生 7 天試用），自備金鑰當一次買斷的進階選項，不放廣告**。一小時錄音成本約 13 台幣，標準方案 NT$290／月給 12 小時，用滿還有三成毛利。但收錢前要先做兩件事：一小時錄音真的穩，加上一台代理伺服器。

## 一、一小時錄音要花多少

| 項目 | 怎麼算 | 美元 |
|---|---|---|
| 轉錄 gpt-transcribe | 60 分鐘 × 0.0045 | 0.27 |
| 潤飾 gpt-5.4-mini 輸入 | 一小時約 1.5 萬字，加提示詞分 4 塊送，約 2.1 萬 token × 0.75／百萬 | 0.016 |
| 潤飾 gpt-5.4-mini 輸出 | 約 1.4 萬 token × 4.50／百萬 | 0.063 |
| 小計 | | 0.35 |
| 重試、失敗重送預留 15% | | 0.05 |
| **每小時** | | **約 0.40 美元 ≈ NT$13** |

- 轉錄占了快八成。要壓成本，該換的是轉錄，潤飾怎麼換都省不了多少。
- 中文一個字算 1 token 是保守估，實際可能少一點。
- 換算：每分鐘約 NT$0.2。講十分鐘 NT$2。

### Apple 抽成之後實收多少

- 台灣售價含 5% 營業稅，Apple 代收代繳。
- 年收入 100 萬美元以下申請 Small Business Program，抽 15%。
- **實收 ≈ 售價 ÷ 1.05 × 0.85 ≈ 售價的 81%**。

## 二、兩條路比一比

### A：免費＋廣告＋自備金鑰

| | |
|---|---|
| 你的 API 成本 | 0（用的人自己付給 OpenAI） |
| 廣告收入 | 很少。生產力 App 一天開幾次、每次停留短，台灣橫幅廣告一個活躍用戶一個月大概幾塊台幣（這是粗估，我沒查到可靠的台灣數字） |
| 最大的卡 | 知識工作者多半不會申請 OpenAI 金鑰：要開平台帳號、綁信用卡、先儲值、再複製一串字貼進來。現在 App 首頁那張金鑰卡，就是大多數人會離開的地方 |
| 隱私 | 廣告 SDK 會追蹤，要跳「允許追蹤」視窗，隱私標籤也要寫「用於追蹤你」。一個會聽你講一小時話的 App 掛這個，信任掉很多 |
| 好處 | 程式幾乎不用改，現在就是這樣做的 |

### B：試用＋訂閱（按時數）

| | |
|---|---|
| 你的 API 成本 | 每小時 NT$13，你出 |
| 收入 | 見第三節 |
| 最大的卡 | 要蓋代理伺服器（金鑰不能放進 App，會被拆出來盜用），要算時數、防濫用、處理審查 |
| 隱私 | 聲音會經過你的伺服器，要寫隱私政策，說清楚不留存 |
| 好處 | 用的人打開就能錄，沒有金鑰這關 |

### 我的建議：B 為主，A 的「自備金鑰」留著當買斷

- 會付錢的是想省時間的人。廣告那條路賺不到錢，還會把最想要的那群人擋在金鑰那一步。
- 自備金鑰的程式已經寫好了，留著給工程師型的用戶：**一次買斷 NT$390 解鎖**，你的成本是 0。
- 不放廣告。

## 三、訂閱方案試算

每小時成本 NT$13。「一般用量」假設平均只用掉額度的 40%（訂閱制常見的情況，你的用戶是長錄音族群，可能偏高，要上線後量）。

| 方案 | 價格 | 每月時數 | 實收 | 用滿成本 | 用滿毛利 | 一般用量毛利 |
|---|---|---|---|---|---|---|
| 輕量 | NT$150／月 | 5 小時 | 122 | 65 | 57（47%） | 96 |
| **標準** | **NT$290／月** | **12 小時** | 235 | 156 | 79（34%） | 173 |
| 重度 | NT$590／月 | 30 小時 | 478 | 390 | 88（18%） | 322 |
| 標準年繳 | NT$2,900／年 | 每月 12 小時 | 每月 196 | 156 | 40（20%） | 134 |
| 加購包 | NT$120 | 5 小時 | 97 | 65 | 32（33%） | — |

- **12 小時是什麼概念**：一週三次、每次一小時散步錄音。每天都錄一小時的人選重度。
- **試用**：用 Apple 的訂閱免費試用（7 天），試用期內上限 3 小時。一個 Apple ID 只能用一次，Apple 幫你擋重複試用。每個試用者最多花你 NT$39。
- **時數沒用完**：不累積到下個月，比較好算。
- **失敗不扣**：轉錄或潤飾失敗的那段不算時數。這條要寫在付費頁，長錄音的人最怕這個。
- **伺服器**：Cloudflare Workers 這類，前幾百個用戶每月幾百台幣內。
- **損益兩平**：伺服器每月約 NT$300、Apple 開發者年費（NT$3,000 左右）攤成每月 250，合計每月約 NT$550。標準方案一般用量 4 個人、全部用滿 7 個人就打平。這沒算你自己的時間。

### 跟 Typeless 比

| | Typeless | 米說（試算） |
|---|---|---|
| 免費 | 每週 8,000 字 | 7 天、3 小時 |
| 月繳 | 30 美元 ≈ NT$960，字數不限 | NT$290，12 小時 |
| 年繳 | 每月 12 美元 ≈ NT$384 | 每月約 NT$242 |
| 計算方式 | 字數 | 錄音時數 |

一小時中文大約 1.5 萬字，照 Typeless 免費版每週 8,000 字，講半小時就用完一週。Typeless 的字數怎麼算中文我沒查到，比較時不要寫死這個數字。

按時數算比較適合你：長錄音的人知道自己講多久，不知道自己講了幾個字。

## 四、米說比 Typeless 好在哪

先講 Typeless 的主場：在任何 App 裡按一下就講，講完字直接打進去。它是鍵盤，給短句用的，Mac、Windows、手機都有，支援很多語言。這塊米說不要去比。

米說能贏的地方，都在「講很久」這件事上：

1. **錄一小時不會丟**。邊錄邊寫檔、被電話打斷會接回、沒網路先排隊、口語稿先存再潤飾。⚠️ 這幾條第一批寫了，真機還沒驗；一小時潤飾會超時，第二批才修。**現在還不能拿這條當賣點**。
2. **潤飾保留你的講法**。「保留原聲」只刪贅字、分段，不改寫成 AI 文章。你要的是拿去改的草稿，改起來要像自己講的。
3. **稿子留得住**。歷史、搜尋、備忘錄式編輯器、原稿對照、字數。Typeless 打完字就交給別的 App，米說自己就是放稿子的地方。
4. **從你的修改學詞彙**。你改過的錯字，下次自動加進詞彙表。
5. **繁體中文、台灣用語**。這要靠第三批「語感」的提示詞做出來。
6. **按時數收費**（如果走 B）。

一句話給用戶聽：**出門走一小時，回家拿到一篇像你寫的草稿。**

## 五、針對「知識工作者長期錄音」還缺什麼

### 收錢之前一定要有

| # | 項目 | 現況 | 為什麼 |
|---|---|---|---|
| 1 | 一小時一定出得來 | 第二批還沒寫：分塊潤飾、等 180 秒、錄音檔留 7 天 | 收了錢的一小時失敗一次，就退訂了 |
| 2 | 鎖屏也整理完＋「好了」通知 | 第四批，還沒定 | 講完收進口袋是常態 |
| 3 | 失敗可以單筆重試 | 沒有 | 搭配「失敗不扣時數」 |
| 4 | 刪除全部資料、Privacy Manifest | 沒有 | 上架審查會擋 |
| 5 | 代理伺服器、時數計算、訂閱頁 | 沒有 | 走 B 才需要，是最大的一塊工程 |

### 會讓知識工作者選你的

| # | 項目 | 說明 |
|---|---|---|
| 6 | 錄音中打點 | 講到重點按一下，稿子上那段標出來。一小時的稿子，最難的是找回剛才那個好想法 |
| 7 | 點段落聽原音 | 懷疑聽錯時，點一下就聽那幾秒。要先有 #1 的「留錄音檔」，gpt-transcribe 給不給時間戳要查證 |
| 8 | 送到電腦 | 知識工作者在電腦上寫。先做分享成 Markdown、送到 Notion／Obsidian／備忘錄；iCloud 同步之後再說 |
| 9 | 接著上一篇錄、兩篇合併 | 散步中途停一次就變兩篇 |
| 10 | 匯入音檔 | 語音備忘錄、講座、Podcast 錄音都能丟進來整理 |
| 11 | 一鍵開錄 | 動作按鈕、控制中心、鎖定畫面計時 |

### 可以晚點

- 標籤、資料夾：稿子上百篇以後才需要。
- 每週回顧（這週講了幾小時、幾篇）：統計卡的延伸。

## 六、我建議的順序

1. 先把第二批做完，你錄一次一小時真的拿到草稿。沒過這關，什麼收費方式都不用談。
2. 找 10～20 個知識工作者用 TestFlight 試，你先出錢（每人一個月最多幾十塊台幣），請他們回報設定頁統計卡的時數。拿真實的每月時數回來定方案，第三節的 40% 才不是猜的。
3. 同時做 #6 打點、#8 送到電腦。
4. 定方案後再做代理伺服器和訂閱（#5）。
5. 上架。

## 七、要你定的

1. 走 B（訂閱）還是 A（廣告＋金鑰）？走 B 的話，`產品定稿.md`「不做付費、不做帳號」那條要改。
2. 方案價格要照第三節，還是你心裡有數字？
3. 第五節 #6～#11，哪幾條對你的用戶最有感？
4. 第二步的試用名單，你身邊找得到 10 個人嗎？
